# Sample world

One dashboard (the Cashboard) carried part-way through the flow, with arbitrary values, so every file shape can be seen filled in. Same tree as the repo root. No skill reads anything in here; the skills read the real folders at the root, which start empty.

To see the portal with this data instead of the empty repo: `npm run graph -w @bank-dashboards/portal -- --sample`, then `npm run dev -w @bank-dashboards/portal`. Run `npm run graph` without the flag to go back to the real files.

Delete this folder once a real dashboard has been through the flow and the real files show every shape.
